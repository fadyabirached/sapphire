# Sapphire — Admin Console

React + Vite + Tailwind console for moderating posts and viewing platform stats.
See the [root README](../README.md) for the full project overview and setup instructions.

```bash
npm install
npm run dev      # start the dev server
npm run lint      # lint
npm run build     # production build
```

Set `VITE_API_BASE_URL` (defaults to `http://localhost:3000`) to point at the Backend API.
